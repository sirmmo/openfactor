OpenFactor

An open source factory-building platform for the browser. The simulation is a deterministic Rust library, and the game is content that runs on top of it.

Play the sandbox API reference Source on GitHub

Status

Early prototype. The core simulation and a single-player sandbox work. There is no multiplayer, data-pack loader or public API yet, and saves are not implemented, so reloading the page starts over.

The one rule

state(t+1) = sim(state(t), commands(t))

The simulation has no clock, no I/O, no floats and no randomised containers. Anything unpredictable enters as a command. Co-op sync, replays and integrations are all planned around this rule. Every run of the same commands produces the same state hash, which the sandbox shows in its top bar.

Playing

The sandbox opens with a working line. Build freely: there are no costs yet.

How the factory works

BuildingBehaviour
MinerMust sit on ore. Outputs through its front.
BeltMoves items toward its front. Several belts or machines feeding one tile take turns.
Smelter1 ore → 1 plate, 30 ticks. Takes input from anything feeding it and outputs through its front.
Assembler2 plates → 1 widget, 60 ticks.
DepotStores anything delivered to it.

The simulation runs at 60 ticks per second. A tile is 256 position units long and belt items sit at least 64 units apart. At the example speed of 16 units per tick, a belt carries one item every 4 ticks.

Embedding the simulation

The openfactor-sim crate has no dependencies. Items, recipes and speeds are passed in as a Content value.

use openfactor_sim::*;

let worldgen = WorldGen { patches: vec![Patch {
    origin: Pos::new(0, 0), width: 1, height: 1,
    item: ItemId(0), amount_per_tile: 1_000,
}]};
let mut world = World::new(Content::example(), &worldgen).unwrap();

world.step(&[Command::Place {
    pos: Pos::new(0, 0), dir: Dir::East, building: Building::Miner,
}]);
println!("{:016x}", world.state_hash());

Building from source

cargo test --workspace
rustup target add wasm32-unknown-unknown
cargo build --profile wasm --target wasm32-unknown-unknown -p openfactor-client-wasm
cp target/wasm32-unknown-unknown/wasm/openfactor_client.wasm site/play/openfactor.wasm
python3 -m http.server --directory site

Roadmap

  1. Headless simulation with replay tests (done).
  2. Browser client with a build and render loop (first version live).
  3. Two browsers in one world, with late join and desync detection.
  4. Data packs and the external API.
  5. WASM mods, then federation between worlds.
